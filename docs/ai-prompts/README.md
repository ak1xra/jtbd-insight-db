# AI プロンプト一覧

Insight DB の各フィールドを **下書き補助** するときに使うプロンプトです。必ず `docs/governance/` を先に読んでください。

| ファイル | 用途 |
|----------|------|
| `insight-name.md` | インサイト名の autofill |
| `forces.md` | Forces（Push/Pull/Anxiety/Habit）の autofill |
| `journey-stage.md` | ジャーニー段階の autofill |
| `summary.md` | 要約の autofill |

## 使い方

- 各 `.md` の「入力」「出力形式」「禁止」をそのままチャットに貼るか、Cursor の User Rules / スニペットに登録する。

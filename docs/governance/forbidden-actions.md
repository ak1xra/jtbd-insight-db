# 禁止事項

## 用語（読み替え）

このファイルの **「確定」** は、Notion の `レビュー状態` プロパティが **`確定`** になっている状態を指す（`下書き` / `レビュー中` を経たうえでの確定）。

## 禁止事項

- 出典のない **固有名詞・数値・引用** を事実として記録しない。
- 人手レビューなしで **`レビュー状態 = 確定`** にしない（システム権限で変更できても原則禁止）。
- 個人を特定しうる情報を、必要以上に Insight に残さない。
- プロンプトや外部ログに、本番の機密トークン・パスワードを貼らない。

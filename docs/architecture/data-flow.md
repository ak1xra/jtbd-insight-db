# データフロー

## 入力から公開まで（概要）

1. **起票**: テンプレートに沿ってドラフト作成（人手またはAI下書き）。
2. **レビュー**: 品質基準・禁止事項を満たすまで修正。
3. **確定**: ステータスを確定状態へ遷移。
4. **連携**: 必要に応じ関連DBと双方向リンクを同期。

## 図（プレースホルダ）

```text
[ソース] --> [Insight DB ドラフト] --> [レビュー] --> [確定] --> [検索・レポート]
                ^                          |
                +---- AI補助（ガバナンス下） --+
```

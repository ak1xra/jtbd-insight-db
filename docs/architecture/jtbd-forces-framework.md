# Forces of Progress（解説）

JTBD における **進歩の力（Forces of Progress）** は、顧客が「雇い替え」を起こすときに働く推進力と抑止力のフレームです。

## 典型的な四分類（例）

| 方向 | 意味（例） |
|------|------------|
| 現状への不満（Push） | 今の解が足りない・不快 |
| 新解への魅力（Pull） | 新しい解のベネフィット |
| 不安・慣性（Anxiety） | 失敗リスク・学習コスト |
| 現状維持（Habit） | 変化の面倒さ・既存投資 |
